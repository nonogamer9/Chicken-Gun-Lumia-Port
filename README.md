# Chicken-Gun-Lumia-Port
A port of Chicken Gun for W10M Based Devices

This is a lumia port of chicken gun which is backported from Unity 2018.2 to the latest Unity that windows phones can handle without lag (which is Unity 2018.1.9f2). This chicken gun port is based on 1.2.6 so expect joining into chicken gun private servers!

* Known Issues:

- None! All of them are now fixed as of October 30th 2026!

* Issues being fixed:

- T Posing mobs (For Some Reason) [This is now fixed after changing the rigs]

- The Shop Is backported to Unity 2018.1.9f1 So expect some small bugs. (this is now fixed)

- Some Shader Bugs can be seen (this is also now fixed)

- Lag Can be expected because some lumias have dx10 issue causing unity lag. (this is an issue with shoving Unity 2018.2 into ARM UWP not 2018.1 so i stand corrected!)
